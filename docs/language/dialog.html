Dialog ​

Overview ​

  • Dialog is an overlay type for focused confirmation and interruption flows.
  • It is commonly anchored to high-impact actions.
  • Keep dialog copy explicit and action-oriented.

Syntax ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12
    [Archive](Button.secondary.sm@dialogTarget)
  ~ Overlay type=dialog anchor=@dialogTarget placement=bottom
    Dialog content.

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12
    [Leave workspace](Button.danger.sm@dialogLeave)

  ~ Overlay type=dialog anchor=@dialogLeave placement=bottom
    Leave without saving pending changes?
