Select ​

Overview ​

  • A choice control used to pick one value from a predefined set while keeping the field compact until expanded.

Use Cases ​

  • Use Select for country, role, team, status, or category choices.
  • Use fill when the field should align with form widths or toolbar widths.
  • Use the open list state when the documentation needs to show the available options explicitly.

Sizes ​

  • Supported today: xxs | xs | sm | md | lg | xxl

States ​

  • Closed select is the default renderer
  • list renders the expanded option list below the trigger
  • placeholder keeps the selected text visually muted
  • Interaction states hover, focused, and active use monochrome high-contrast affordances
  • Validation message renders a state icon when state=success|warning|error
  • state=error renders with stronger emphasis and a 3px external border while keeping the field size consistent

Content ​

  • The label is the current selected value in the closed trigger
  • For open-list examples, separate options with |
  • value="..." selects the matching list option when list or open is used
  • If value is missing or does not match, the first option is selected by default
  • Supports a leading inline icon

Layout ​

  • Supports fill

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack
    # Select - all combinations exercised

    ~ Grid cols=3
      [Country](Select.placeholder.sm)
      [Argentina](Select.md)
      [Design systems](Select.lg)

      [[globe](Icon) Country](Select.sm)
      [Status](Select.placeholder.md.fill)
      [Owner](Select.lg.fill)

    ~ Stack horizontal
      [Argentina | Brazil | Chile | Uruguay](Select.list.md value="Chile")
      [[clock](Icon) Today | This week | This month | This quarter](Select.list.lg value="This week")

    [The list token expands the option menu, and value chooses the selected row.](Text.sm)
