Supported Surface (Runtime Exhaustive) ​

This page lists every currently supported OUi language surface according to runtime schema exports.

Source-of-truth snapshot date: April 27, 2026.

Canonical source used for this page: apps/editor/src/language/schema.ts.

Use /language/formal-spec for the formal entry point and links to grammar/AST specs.

Parser Features Beyond Schema ​

This section documents parser-supported language behavior that is not fully represented by directive/component token tables.

Comments ​

  • HTML comment blocks are supported and skipped by the parser:
html
<!--
  this block is ignored
-->

Literal Escaping ​

  • Prefix a shortcut-like line with !! to force plain text:
    • !!---
    • !![x] Done
    • !!(12)
  • See /language/shortcuts.

DataGroup Expansion ​

  • % DataGroup ... is parsed as an expansion directive before final AST emission.
  • Supported attributes are listed below in this page (repeat=, fake, fake=).
  • Applies to the next block node.
  • Without fake, DataGroup preserves the original block content by default.
  • Bare fake forces deterministic fake-data replacement with fallback values.
  • See /language/datagroup.

Definitions, Include, And Slots ​

  • Document-local definitions use:
    • ~ Definitions
    • child entries like ~ CardShell
  • Include syntax is [>](Name) or [>](Name.tokens).
  • Includes can carry nested slot overrides as children.
  • Parser resolves includes/definitions and warns on unknown slots and cycles.
  • See /language/includes.

Shortcut Surface ​

  • Divider shortcut: --- becomes ~ Divider.
  • Checkbox shortcuts:
    • [ ] Label
    • [x] Label
  • Choice control shortcuts:
    • ( ) Label
    • (x) Label
    • (o) Label
  • Standalone badge shortcut:
    • (12) becomes Badge.
  • See /language/shortcuts.

Tables And Cell Alignment Shortcuts ​

  • DataGrid is the official table authoring surface in OmniUI.
  • Markdown table rows are normalized as an implicit DataGrid wrapper.
  • Inside that wrapper, runtime table structure is represented as Table / TableRow / TableCell.
  • Cell-level alignment shortcuts are supported:
    • : value : for center
    • value : for right
  • See /language/tables.

List Parsing ​

  • Markdown list markers parse to list nodes:
    • unordered: -, *, +
    • ordered: 1.

Component-Level Property Lines ​

  • Components can receive multiline property lines directly below the component:
OmniUI
Codeomniui
[Email](Input)
  - placeholder="name@example.com"
  - required

Required Label Marker ​

  • A trailing * in component label marks required semantics.
  • Guardrails in parser avoid false-positive conversion for:
    • standalone *
    • markdown closers such as **bold** and ***bold italic***

Fenced Code Blocks ​

  • Fenced markdown code blocks are preserved as text nodes (not interpreted as DSL directives/components).

Tabs Expansion ​

  • Tabs component input is expanded by parser into sibling Tab components.
  • Supports selected=, size=, variant=, orientation=, and platform= resolution during expansion.
  • ~ Ui platform=mobile is inherited by descendant Tab/Tabs nodes that do not set platform explicitly.
  • See /language/tab.

Compatibility And Deprecation Rules ​

  • ~ Ui is the only root directive.
  • ~ Screen is rejected with a parser error.
  • Inline [...](Card...) is accepted with deprecation warning; prefer container ~ Card.
