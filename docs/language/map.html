Map ​

Overview ​

  • Map renders a fixed grayscale map image placeholder.
  • It is designed for static mockups where you need map context without integrating live map providers.
  • Route overlays and marker overlays are rendered in black.

Use Cases ​

  • Showing a static city map area in app mockups.
  • Simulating marker states (pin, GPS, navigation pointer) over the same base image.
  • Simulating route state independently of marker state.
  • Keeping map visuals deterministic for design reviews and QA snapshots.

Syntax:

OmniUI
Codeomniui
[Label](Map.tokens attrs)

Supported tokens and attributes:

  • Layout: fill
  • Rendering: skeleton
  • Mode: mode=static|route
  • Marker: marker=none|pin|gps|navigation
  • Note: marker= is supported only when mode=static.
