Toast ​

Overview ​

  • Toast communicates non-blocking status updates.
  • It is a container with semantic decoration and free content.
  • Use semantic to choose default status styling and default leading icon.

Use Cases ​

  • Use Toast for non-blocking confirmations, warnings, background progress updates, and action feedback.
  • Keep toast content concise and actionable when needed.

Syntax ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12
    ~ Toast semantic=info
      [Informational](Text.md)
      [Secondary information](Text.md)

Attributes ​

  • semantic=: info | success | warning | error

  • Why: defines message intent first, then visual defaults.

  • Purpose: maps to default leading icon and status treatment in a deterministic way.

  • leading=: overrides default semantic icon (leading=upload, leading=download, etc.)

  • Why this name (not icon): leading models the start slot position, not only icon type.

  • Purpose: keeps the API future-proof if the leading slot evolves beyond icon-only content.

  • dismissible=: true | false (defaults to true)

  • Why: makes close affordance explicit when you need non-dismissible progress/flow messages.

  • Purpose: controls whether the trailing dismiss action is rendered.

  • Layout attributes supported: width=, w=, padding=, gap=, rounded=, surface=, border

  • Why: Toast is a container, so sizing/spacing/chrome must stay controllable by layout rules.

  • Purpose: lets teams align toast framing with dense or spacious surfaces without forking behavior.

Attribute Design Notes ​

  • semantic is the canonical intent attribute in OmniUI for this component category.
  • variant remains reserved for visual style axes where needed.
  • type is intentionally not used for Toast because type is already used by Overlay for structural modes (tooltip, popover, bottom-sheet, etc.).

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=16 padding=12
    ~ Toast semantic=info
      [Informational](Text.md)

    ~ Toast semantic=success
      [Success](Text.md)

    ~ Toast semantic=warning
      [Warning](Text.md)

    ~ Toast semantic=error
      [Error](Text.md)

    ~ Toast semantic=info leading=upload
      [Upload completed](Text.md)

    ~ Toast semantic=info
      [Informational](Text.md)
      [Secondary information](Text.md)
      [30% complete](Text.sm)
      [Progress](ProgressBar.fill.showLabel value="30")

    ~ Toast semantic=info
      [Informational](Text.md)
      [Secondary information](Text.md)
      [Action](Button.ghost.sm)
