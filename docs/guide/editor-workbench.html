Editor Workbench ​

This section groups the workflows for the OUi editor experience:

  • source authoring in the code editor
  • structure-first visual editing in the SVG preview
  • export and clipboard actions for downstream design tools

Code Editor ​

The code editor is the source of truth for every screen. It provides:

  • syntax-aware highlighting and visual affordances for directives, components, and tokens
  • multiline editing for props and structured blocks
  • sample-aware navigation with canonical sample URLs
  • source formatting and search helpers

For details about the visual syntax layer used by the editor, see Editor Visual Syntax.

Visual Editor and SVG Preview ​

The visual side of the playground renders the same AST through the SVG renderer and keeps selection synchronized with source lines.

Core behaviors:

  • click a node in preview to focus the matching source range
  • inspect and highlight layout or component targets
  • use fullscreen and fit modes for larger compositions

For the docs renderer behavior, see Live Preview.

Design Mode: Tabs and Navigation Lists ​

When you work with Tab or NavItem groups in Design Mode, the preview exposes quick controls to speed up list editing:

  • + Tab adds a new Tab item inside the current tabs group.
  • + NavItem adds a new NavItem item inside the current navigation group.

After insertion, a contextual shortcut hint appears near the inserted component and auto-hides after a few seconds. You can disable future hints with Don't show again in that hint panel.

Keyboard Shortcuts for Group Editing ​

Use these shortcuts while your selection is inside a Tab or NavItem group:

  • Cycle the active item:
    • macOS: Option + Left/Right or Cmd + Left/Right
    • Windows/Linux: Alt + Left/Right
  • Move the selected item up/down:
    • macOS: Option + Shift + Up/Down or Cmd + Shift + Up/Down
    • Windows/Linux: Alt + Shift + Up/Down

Notes:

  • Active state cycling updates Tab.selected or NavItem.active in source.
  • Reordering preserves source structure and follows the visible group order.
  • For the full shortcut catalog across all components/workflows, see Keyboard Shortcuts.

Visual Walkthrough (Tabs Interaction) ​

The editor supports a repeatable visual flow for keyboard interactions in tabs/navigation groups:

  1. Keep the caret inside a Tabs/Tab group to target that component context.
  2. Use Alt + Left/Right (Cmd + Left/Right on macOS) to cycle the active item.
  3. Press F1 (or Alt + /) to open the shortcut hint panel for the current component.

Copying SVG from the Preview ​

You can copy SVG directly from preview selection:

  • Cmd+Shift+C on macOS
  • Ctrl+Shift+C on Windows/Linux

Behavior:

  • if a preview node is selected, the editor copies that node as a standalone SVG
  • if no preview node is selected, the editor copies the full preview SVG

This is useful when pasting wireframe fragments into design tools like Figma.

Clipboard Image Paste and Materialization ​

When you paste an image into the code editor, OUi inserts a markdown image with an embedded data URL so the document remains portable across Playground and VS Code:

  • ![Alt text](data:image/... | border=none width=... height=...)

Why this flow exists ​

  • preserves visual parity between editors
  • keeps pasted screenshots/SVGs portable when sharing source files
  • avoids local-only clipboard references that can break across sessions

You can also call the same behavior from the browser console:

js
await window.OUi.export.copyMaterializedDoc();
window.OUi.export.materializePastedImages();
