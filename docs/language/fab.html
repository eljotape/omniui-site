FAB ​

Overview ​

  • FAB is an overlay type for the highest-priority screen action.
  • Overlay type=fab supports compact icon-only and extended labeled variants.
  • Use one primary FAB per screen region to avoid competing top-level actions.
  • For centered docked mobile navigation actions, prefer Bottom App Bar with fab=center.

Syntax ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12 id=fabHost
    [Main canvas](Text.md)
  ~ Overlay type=fab anchor=@fabHost placement=bottom-right fabSize=medium fabVariant=surface icon=edit

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12 id=fabExamplesHost
    [Project board](Text.md)

  ~ Overlay type=fab anchor=@fabExamplesHost placement=bottom-right fabSize=small fabVariant=surface icon=edit

  ~ Overlay type=fab anchor=@fabExamplesHost placement=bottom fabSize=medium fabVariant=primary icon=plus
    Create

  ~ Overlay type=fab anchor=@fabExamplesHost placement=bottom-left fabSize=large fabVariant=secondary icon=compass lowered
