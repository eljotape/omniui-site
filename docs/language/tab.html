Tab ​

Overview ​

  • Tab represents one selectable item inside a tablist.
  • Use it for category switching inside the same content context.

Use Cases ​

  • Use Tab inside settings pages, dashboards, and editor views where content groups share the same screen context.

States ​

  • Supports selected
  • Supports disabled
  • Supports static preview state via visual=default|hover|pressed|focused

Size and Variant ​

  • Supported sizes: sm | md
  • Supported variants: underline | pill
  • Default size is md
  • Default variant is underline

Orientation ​

  • orientation=horizontal|vertical controls indicator direction.
  • Horizontal tabs show a bottom underline when selected.
  • Vertical tabs show a leading-side indicator when selected.

Platform ​

  • platform=desktop|mobile is supported on both Tab and Tabs.
  • desktop is the default when platform is omitted.
  • ~ Ui platform=mobile applies mobile defaults to descendant Tab/Tabs nodes unless a local platform override is set.

Compact Expansion (Tabs) ​

  • [Overview | Details | Settings](Tabs selected=0) expands into sibling Tab nodes.
  • Per-item visual state can be declared with ::state, for example Overview::focused.
  • Tabs is authoring sugar; Tab is the final renderable component.

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12
    # Tab - all combinations exercised

    ~ Stack horizontal gap=8 role=tabs
      [Overview](Tab.selected.md.underline)
      [Details](Tab.md.underline)
      [Settings](Tab.md.underline disabled)

    ~ Stack horizontal gap=8 role=tabs
      [[calendar](Icon) Timeline](Tab.sm.pill.selected)
      [[image](Icon) Team](Tab.sm.pill)
      [[chart-bar](Icon) Metrics](Tab.sm.pill)

    ~ Stack gap=8 role=tabs
      [Overview](Tab.selected.md.underline orientation=vertical)
      [Details](Tab.md.underline orientation=vertical visual=focused)
      [Settings](Tab.md.underline orientation=vertical)

    [Overview::focused | Details::hover | Settings::disabled](Tabs selected=0 size=sm variant=pill orientation=horizontal)

    ~ Stack horizontal gap=0 role=tabs width=fill
      [[mail](Icon) Mail](Tab.md platform=mobile)
      [[bell](Icon) Alerts](Tab.md platform=mobile)
      [[message-circle](Icon) Chat](Tab.selected.md platform=mobile)
