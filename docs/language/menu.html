Menu ​

Overview ​

  • A floating command surface that renders grouped menu actions with optional shortcuts and nested-action affordances.

Use Cases ​

  • Use Menu for context actions, overflow actions, command palettes in compact mode, or profile/action menus.
  • Use section headers to group related commands.
  • Use dividers to separate destructive actions, workspace actions, or navigation actions.

Sizes ​

  • Supported today: xxs | xs | sm | md | lg | xxl

Content model ​

  • Separate rows with |
  • Divider row: ---
  • Section row: prefix with # (example: # Section header)
  • Shortcut text: Action::Ctrl+K
  • Submenu affordance: append >> (example: Export as...>>)
  • Checked row: prefix with [check](Icon)
  • Optional leading icon in each row is parsed from the row text (emoji or mapped icon glyphs)

Layout ​

  • Supports fill

Tokens ​

  • checkmark reserves a leading check column even when a row is not currently selected.
  • skeleton renders the menu as a placeholder.

Examples ​

OmniUI

~ Ui
  ~ Stack gap=md
    # Menu - all combinations exercised

    ~ Stack horizontal alignV=start gap=md
      [# File | [edit](Icon) Rename::F2 | [clipboard](Icon) Duplicate::Ctrl+D | --- | [check](Icon) [pin](Icon) Pin to sidebar::Ctrl+P | [share](Icon) Share with...>>](Menu.md)
      [[search](Icon) Find::Ctrl+F | [compass](Icon) Go to line::Ctrl+G | --- | [settings](Icon) Settings](Menu.sm)

    ~ Stack width=360
      [[user](Icon) Invite member::I | [link](Icon) Copy link::Ctrl+Shift+C | --- | [trash](Icon) Clear recent::Del | [trash](Icon) Delete workspace::Ctrl+D](Menu.fill)
