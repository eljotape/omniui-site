Divider ​

Overview ​

  • A visual separator used to organically divide content or layout sections.
  • Can be horizontal or vertical.
  • Supports expanding gracefully across the layout container axis.

Use Cases ​

  • Use Divider to visibly separate distinct groups of content.
  • Use vertical to separate items in a horizontal stack or toolbar.
  • Use fill when the divider should adaptively span the parent container's width or height.

Layout Options ​

  • Renders a horizontal line by default.
  • vertical turns it into a vertical line.
  • fill is enabled by default and makes the divider expand along the layout container's cross-axis.
  • Use fill=false to keep the divider decorative/intrinsic.
  • width overrides with an explicit width in pixels.
  • height overrides with an explicit height in pixels.
  • Inside a hug parent, Divider fill=false stays decorative by default:
    • it visually spans the intrinsic content slot derived from its siblings
    • it does not expand the intrinsic size of the hugging parent to the full probe box
  • Use default fill, width=, or height= when the divider should participate in intrinsic sizing.

Markdown Shortcut ​

A standalone Markdown horizontal rule (---) is automatically interpreted as a Divider (same default behavior as ~ Divider).

markdown
First block

---

Second block

To render --- literally instead of expanding it into a divider, prefix it with !!:

OmniUI
Codeomniui
!!---

  ~ Stack

    ~ Divider

    ~ Divider fill=false

    ### Fixed width priority
    ~ Divider width=240

    ### Vertical divider inside Stack
    ~ Stack horizontal
      [Item Left](Text.sm)
      ~ Divider vertical
      [Item Right](Text.sm)

    ### Filling constrained sizes
    ~ Stack horizontal height=80 surface=muted border
      [Full height span](Text.sm)
      ~ Divider vertical fill
      [Full height span](Text.sm)

    ### Fixed height vertical divider 
    ~ Stack horizontal
      [Item A](Text.sm)
      ~ Divider vertical height=40
      [Item B](Text.sm)
