Icon ​

Overview ​

  • A compact visual symbol representing an action, status, or concept.

Use Cases ​

  • Use Icon for common affordances such as search, settings, help, and notifications.

Syntax ​

OmniUI
Codeomniui
[search](Icon.xxs)
[search](Icon.xs)
[mail](Icon.sm)
[search](Icon)
[qr](Icon)
[settings](Icon.lg)
[search](Icon.xxl)

Behavior ​

  • Icon renders an icon-only semantic component.
  • The label provides the semantic icon name.
  • Supported size tokens:
    • xxs (16px)
    • xs (20px)
    • sm (24px)
    • md (32px)
    • lg (44px)
    • xxl (88px)
  • Default size is md.

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ DataGrid
    | Size | Icon                |
    | ---- | ------------------- |
    | xxs  | [search](Icon.xxs)  |
    | xs   | [search](Icon.xs)   |
    | sm   | [search](Icon.sm)   |
    | md   | [search](Icon)      |
    | md   | [qr](Icon)          |
    | lg   | [search](Icon.lg)   |
    | xxl  | [search](Icon.xxl)  |

Notes ​

  • Icon uses the same semantic icon mapping pipeline as emoji-expanded icons.
  • If you already know the semantic name, Icon is the explicit form.
  • If you prefer quick authoring, emoji-to-icon expansion still works in labels and text.
