NavItem ​

Overview ​

  • A navigation row used to represent a destination, section, or mailbox-like entry in a list of destinations.

Use Cases ​

  • Use NavItem inside side navigation, section menus, and list-based app shells.
  • Use the active token to indicate the current destination.
  • Pair it with Badge when the destination needs a small count indicator.

States ​

  • Supports active
  • Supports fill to occupy the full available row width
  • Active state is visually differentiated by the current renderer

Content ​

  • Supports text labels
  • Supports inline icons

Composition ​

  • Works as a standalone navigation row
  • Works paired with Badge

Anchoring ​

  • Supports @id
  • Useful for navigation-related overlays
