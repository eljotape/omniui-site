Badge ​

Overview ​

  • A small circular marker used to display compact metadata such as a count, a short token, or a minimal state hint.

Use Cases ​

  • Use Badge for unread counts, item totals, and tiny state markers.
  • Use an empty badge when presence matters more than the specific value.
  • Keep content extremely short because the text is clipped to the circle.

Shape ​

  • Renders as a circle, not a pill
  • If no text is provided, the circle remains empty

Content ​

  • Supports empty content
  • Supports short text
  • Supports numeric text
  • Clips long text inside the circle

Composition ​

  • Works as a standalone marker
  • Works next to NavItem as a compact count indicator

Shortcut ​

A standalone parenthesized token with 1 to 4 alphanumeric characters is parsed as a badge.
