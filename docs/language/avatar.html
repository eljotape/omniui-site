Avatar ​

Overview ​

  • A compact identity marker used to represent a person, account, or actor in the interface.

Use Cases ​

  • Use Avatar in headers, profile actions, account menus, and participant lists.
  • Use avatar anchors when account-related Overlays or menus need a clear attachment point.

Content ​

  • Supports icon avatars
  • Supports initials avatars
  • Supports photo avatars when the label is an image path or URL

Variants ​

  • Supported today: icon | initials | photo
  • icon renders a generic account glyph
  • initials renders the initials derived from the label
  • photo renders a clipped circular image when the label is a valid image path or URL
  • In sketchy stroke style, photo falls back to the generic avatar icon (no image fill)

Sizes ​

  • Supported today: xxs | xs | sm | md | lg | xxl
  • Default size: md

States ​

  • Supported today: online | away | busy | offline
  • These tokens render a small presence badge on the avatar

Anchoring ​

  • Supports @id
  • Common target for account and profile overlays
