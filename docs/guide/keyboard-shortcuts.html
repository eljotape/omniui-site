Keyboard Shortcuts ​

This page centralizes the editor keyboard interactions by component/workflow.

Scope Rules ​

  • Most shortcuts apply only when focus is in the code editor or preview.
  • Shortcuts are ignored while typing in native form controls outside OmniUI Editor (input, textarea, select).
  • Arrow-based shortcuts use this direction rule by default:
    • previous: Left or Up
    • next: Right or Down

Tabs and Navigation Groups (Tab, NavItem, Tabs) ​

Use these while your cursor/selection is inside a tabs or navigation group.

  • Cycle active item:
    • macOS: Option + Left/Right or Cmd + Left/Right
    • Windows/Linux: Alt + Left/Right
  • Reorder selected item:
    • macOS: Option + Shift + Up/Down or Cmd + Shift + Up/Down
    • Windows/Linux: Alt + Shift + Up/Down
  • Show shortcut hint toast:
    • F1
    • Alt + /

DataGrid ​

Use these while selection/caret is inside a DataGrid table row.

  • Cycle active column focus:
    • macOS: Option + Left/Right or Cmd + Left/Right
    • Windows/Linux: Alt + Left/Right
  • Reorder current column:
    • macOS: Option + Shift + Left/Right or Cmd + Shift + Left/Right
    • Windows/Linux: Alt + Shift + Left/Right

Input ​

Use while selection is on or near an Input component.

  • Cycle Input presets:
    • macOS: Option + Arrow
    • Windows/Linux: Alt + Arrow

Button ​

Use while selection is on or near a Button component.

  • Cycle Button presets:
    • macOS: Option + Arrow
    • Windows/Linux: Alt + Arrow

Behavior:

  • Vertical arrows switch variant families.
  • Horizontal arrows switch interaction state presets.

Select ​

Use while selection is on or near a Select component.

  • Cycle Select presets:
    • macOS: Option + Arrow
    • Windows/Linux: Alt + Arrow

SpinButton ​

Use while selection is on or near a SpinButton component.

  • Cycle SpinButton presets:
    • macOS: Option + Arrow
    • Windows/Linux: Alt + Arrow

Overlays (Drawer, Bottom Sheet, Dialog, Modal, Popover, Tooltip) ​

Use while selection is on or near an overlay directive of the same type.

  • Cycle overlay presets:
    • macOS: Option + Arrow
    • Windows/Linux: Alt + Arrow

Behavior:

  • Horizontal arrows rotate placement options.
  • Vertical arrows rotate variant options.

Tooltip variant behavior:

  • Up/Down toggles tooltip style variants (default / inverted) while preserving placement.
  • Left/Right rotates the full placement ring (top-left → ... → left-top → none → center) while preserving variant attrs.

Stack ​

Use while selection is on a ~ Stack directive line (not inside a component line).

  • Set stack direction:
    • macOS: Option + Arrow
    • Windows/Linux: Alt + Arrow

Behavior:

  • Left/Right sets horizontal.
  • Up/Down sets vertical.

Virtual Template Editor ​

When virtual template mode is active and focus is on a virtual-template field:

  • Cycle field values:
    • macOS: Cmd + Arrow

General Editor and Preview ​

  • Toggle Design Mode:
    • macOS: Cmd + Shift + D
    • Windows/Linux: Ctrl + Shift + D
  • Copy selected preview node SVG (when preview is active/hovered/selected):
    • macOS: Cmd + Shift + C
    • Windows/Linux: Ctrl + Shift + C
  • Open Find & Replace:
    • macOS: Cmd + F
    • Windows/Linux: Ctrl + F

Escape Behavior ​

  • Esc closes About dialog if open.
  • Esc exits DataGrid editor affordances if open.
  • Esc exits Design Mode if active.
  • Esc closes Virtual Template Editor if active.
  • Esc clears locked preview inspect target.
