Drawer ​

Overview ​

  • Drawer is an overlay type for side-panel navigation and secondary workspace tools.
  • It is anchored to a region and can dim the rest of the UI with backdrop.
  • Use drawer content for navigation, filters, and secondary panels.

Syntax ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12 id=workspaceArea
    [Workspace canvas](Text.md)
  ~ Overlay type=drawer anchor=@workspaceArea placement=left backdrop width=260
    Drawer content.

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=12 padding=12 id=workspaceMain
    [Current workspace](Text.md)
    [Open drawer](Button.secondary.sm@workspaceMain)

  ~ Overlay type=drawer anchor=@workspaceMain placement=right backdrop width=280
    Navigation, Inspectors, Assets, and Tokens.
