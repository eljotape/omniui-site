DataGroup ​

  • Implemented in parser expansion layer
  • expands before AST emission
  • not rendered as a runtime node

Overview ​

DataGroup is an authoring directive used to repeat the next block node and optionally populate it with fake data hints.

It belongs to the expansion layer, not to the core AST of OmniUI.

That means:

  • it expands before the final AST is emitted
  • it does not survive as a runtime/render node

Syntax ​

md
% DataGroup repeat=5
% DataGroup repeat=5 fake
% DataGroup repeat=5 fake=[avatarName,messageHeader,message]

Meaning ​

  • repeat=5 repeats the next block 5 times
  • fake enables fake-data replacement with default fallback values
  • fake=[...] provides semantic hints to populate text-bearing leaves

Scope ​

DataGroup applies to the next block node only.

Example:

md
~ Stack scroll role=messages

  [Today](Text.sm)

  % DataGroup repeat=5 fake=[avatarName,messageHeader,message]

  ~ Stack horizontal
    [Nora Kim](Avatar.initials.sm.online)
    ~ Stack border surface=raised
      [Nora Kim · 11:08](Text.sm)
      [I uploaded the latest mobile explorations for the design review. The navigation feels cleaner, but the filters still compete with the primary action.](Text.sm)

The % DataGroup ... line applies only to the next ~ Stack horizontal block.

Runtime Behavior ​

DataGroup runs as a parser expansion pass and does not survive as a runtime node.

Expansion semantics:

  1. The parser locates % DataGroup ....
  2. It targets only the next sibling block node.
  3. It clones that node repeat times.
  4. If fake replacement is active, it walks text leaves in document order and replaces content using fake hints cyclically.
  5. It emits only normal expanded nodes.

Repetition And Fake Rules ​

DataGroup now follows a single rule:

  • no fake attribute => preserve the source block exactly
  • fake => replace text-bearing leaves with default deterministic fake values
  • fake=[...] => replace text-bearing leaves with the provided deterministic hint sequence

Example: pure repeater

OmniUI
Codeomniui
% DataGroup repeat=3
~ Stack horizontal gap=8 padding=8
  [Joe Oui](Avatar.initials)
  ~ Stack gap=0 width=fill
    [**Joe Oui**](Text)
    [Service window has ended.](Text.sm)
    [15/2/26](Text.sm)

Example: fallback fake data

OmniUI
Codeomniui
% DataGroup repeat=3 fake
~ Stack horizontal gap=8 padding=8
  [User](Avatar.initials)
  [Status update](Text.sm)

Leaf replacement target set:

  • Text nodes
  • Component labels

Leaves are replaced in traversal order, and hints are reused cyclically when there are more leaves than hints.

Example with cyclic mapping:

OmniUI
Codeomniui
% DataGroup repeat=2 fake=[fullName,shortTime]
~ Stack horizontal
  [User](Text)
  [11:10](Text.sm)
  [Status](Badge)

The hint sequence applied to leaves is:

  • leaf 1 -> fullName
  • leaf 2 -> shortTime
  • leaf 3 -> fullName (cycle restarts)

Defaults And Validation ​

  • Default repeat: 1
  • repeat is parsed as integer and clamped to >= 0
  • If repeat <= 0, no clones are emitted
  • Default mode without fake: clone/preserve content
  • fake without a value falls back to sentence-like values
  • fake=[...] enables fake replacement with the provided hints
  • fake=[] preserves original content
  • Unknown fake hint names fallback to sentence-like values
  • If no next block exists, parser emits warning and does not expand

Fake Data Hints Reference ​

Supported hints:

  • avatarName
  • fullName
  • firstName
  • shortTime
  • date
  • message
  • sentence
  • paragraph
  • title
  • email
  • company
  • count

Composite hints:

  • messageHeader
  • commentHeader
  • videoMeta
  • mailSubject
  • mailSender

Hint semantics ​

  • avatarName: short first-name style value
  • firstName: first name
  • fullName: first + last name
  • shortTime: time-like value (for example 11:08)
  • date: date-like value
  • message: short message sentence
  • sentence: short sentence (default fallback style)
  • paragraph: longer two-sentence style value
  • title: title/subject style phrase
  • email: deterministic email-like string
  • company: organization name
  • count: numeric counter as text
  • messageHeader: Full Name · HH:MM
  • commentHeader: Full Name commented
  • videoMeta: media metadata style text
  • mailSubject: subject-like line
  • mailSender: sender/company-like name

Warning Semantics ​

DataGroup issues parser warnings (not fatal errors) for authoring mistakes such as:

  • missing following block node
  • invalid/missing repeat value fallback cases
  • unknown fake hints (resolved with fallback value style)

Expansion Model ​

  1. parse % DataGroup ...
  2. associate it with the next block node in the same parent scope
  3. clone that node repeat times
  4. optionally replace leaf text in document order using the provided fake hints
  5. emit only the expanded normal AST nodes

Determinism ​

  • Fake values are deterministic (stable for snapshots/tests).
  • DataGroup does not require faker-js.
