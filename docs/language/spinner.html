Spinner ​

Overview ​

  • Spinner communicates indeterminate progress while a process is still running.
  • Use it when completion time is unknown and a determinate progress bar would be misleading.
  • If you know the completion amount, prefer ProgressBar.

Use Cases ​

  • Background save and sync states.
  • Async fetch or data refresh operations.
  • Transitional states before showing final content.

Sizes ​

  • Supported today: xxs | xs | xsmall | sm | md | lg | xl | xxl
  • Default size: md

Semantics ​

  • Spinner is indeterminate; it does not expose percent-complete semantics.
  • Supports skeleton as a rendering token.

Layout ​

  • Renders an inline indicator with optional label text from the component body.
  • Does not support fill; width hugs content.
