Slider ​

Overview ​

  • Slider represents a bounded numeric value that users adjust continuously (or by steps).
  • Use Slider when rough value selection is preferred over exact text entry.
  • For exact numeric entry, prefer Input.number or SpinButton.number.

Use Cases ​

  • Use Slider for media volume, brightness, thresholds, and any bounded range selection that users actively adjust.
  • Prefer stepped when users must choose discrete values.
  • For read-only completion state, use ProgressBar.

Syntax ​

OmniUI
Codeomniui
[Label](Slider.tokens attrs)

Common example:

OmniUI
Codeomniui
[Volume](Slider.fill.showLabel value="65" min="0" max="100")

Tokens ​

  • Size: sm, md, lg (default md)
  • Layout: fill
  • Behavior: stepped
  • Rendering: skeleton

Attributes ​

  • showLabel
  • value="number"
  • min="number" (default 0)
  • max="number" (default 100)
  • step="number" (default 1; used when stepped is present)
  • state=default|hover|focused|active|success|warning|error
  • message="..."
  • disabled
  • required

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=lg padding=20 width=680
    # Slider - all combinations exercised
    Reference sample for `Slider` sizes, stepped mode, validation, and disabled state.

    ~ Grid cols=2 gap=lg
      ~ Stack gap=md
        [Volume sm](Slider.sm.showLabel value="30")
        [Volume md](Slider.md.showLabel value="55")
        [Volume lg](Slider.lg.showLabel value="80")

      ~ Stack gap=md
        [Brightness](Slider.fill.showLabel value="70" min="0" max="100")
        [Quality](Slider.fill.stepped showLabel value="2" min="0" max="4" step="1")
        [Critical threshold*](Slider.fill showLabel value="10" min="0" max="100" state=error message="Threshold is too low.")
        [Read-only baseline](Slider.fill.showLabel value="40" disabled)
