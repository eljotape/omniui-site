LLM-Friendly Design ​

OUI was designed to work well not only for humans, but also for language models.

Its syntax and structure make it easy for LLMs to:

  • read UI structures
  • generate new UI samples
  • refactor layouts
  • detect repeated patterns
  • transform interfaces

This makes OUI especially powerful when combined with AI-assisted tooling.

Why typical UI code is difficult for LLMs ​

Most UI languages mix multiple concerns:

  • layout
  • styling
  • behavior
  • framework abstractions
  • state management

Example in HTML:

html
<div class="flex flex-col gap-4">
  <label>Email address</label>
  <input type="email" placeholder="name@example.com"/>
</div>

This representation introduces noise:

  • class-based styling
  • structural wrappers
  • HTML semantics unrelated to layout intent

For language models, this makes it harder to infer the actual UI structure.

OUI expresses intent directly ​

OUI removes most of this noise.

The same UI expressed in OUI:

OmniUI
Codeomniui
[Email address](Input.email.fill)
  - placeholder="name@example.com"

The intent is immediately clear:

  • component type
  • semantic label
  • input variant
  • placeholder value

This clarity improves reliability when generating or transforming UI.

Tree-based structure ​

OUI documents are structured as simple hierarchical trees.

Example:

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=lg

    ~ Form showLabels

      [Email address*](Input.email.fill)
        - placeholder="name@example.com"

      [Password*](Input.password.fill)

      [Sign in](Button.primary)

The indentation directly represents layout hierarchy.

This structure is extremely easy for LLMs to:

  • parse
  • extend
  • restructure
  • analyze

Minimal primitives ​

OUI intentionally keeps the layout system small.

Core layout primitives:

OmniUI
Codeomniui
Ui
Stack
Grid
Spacer
Divider

Because there are only a few layout concepts, language models can learn patterns quickly and apply them consistently.

Predictable syntax ​

OUI uses a small number of predictable syntactic patterns.

Layouts:

OmniUI
Codeomniui
~ Stack gap=md

Components:

OmniUI
Codeomniui
[Label](Component.variant)

Properties:

OmniUI
Codeomniui
- placeholder="name@example.com"

These patterns are consistent across the entire language.

This dramatically reduces ambiguity.

Pattern detection ​

OUI's structural clarity allows tools and models to detect repeated UI patterns.

Example:

OmniUI
Codeomniui
~ Stack
  ~ Stack horizontal
    [Avatar]
    [Message]

  ~ Stack horizontal
    [Avatar]
    [Message]

Language models can easily recognize this as a repeated structure.

This enables features such as:

  • Virtual Templates
  • automated refactoring
  • layout normalization
  • pattern extraction

UI transformation ​

Because OUI separates layout from appearance, it becomes easier for models to perform structural transformations.

Examples:

  • convert a list layout into a grid
  • extract repeated structures
  • reorganize layouts
  • generate alternative UI compositions

Example transformation:

OmniUI
Codeomniui
~ Stack
  Item
  Item
  Item

to:

OmniUI
Codeomniui
~ Grid cols=3
  Item
  Item
  Item

This kind of transformation is much harder in traditional UI code.

AI-assisted editing ​

OUI is designed to work well with AI-assisted editors.

Typical workflows include:

  • generating UI samples
  • editing large layouts
  • restructuring screens
  • detecting layout issues
  • extracting reusable patterns

Because OUI documents are readable and structured, models can operate on them with high accuracy.

Self-contained UI descriptions ​

OUI documents describe UI structure without relying on external framework code.

This makes them ideal for:

  • AI generation
  • documentation
  • automated tooling
  • visual editors
  • UI analysis

The document itself contains the complete structural representation of the interface.

Summary ​

OUI is LLM-friendly because it provides:

  • clear hierarchical structure
  • minimal layout primitives
  • predictable syntax
  • explicit component intent
  • low syntactic noise

These characteristics make OUI a strong foundation for AI-assisted UI design and tooling.
