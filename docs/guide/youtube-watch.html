YouTube Watch Example ​

This example recreates a YouTube-style watch page with a dense content column, channel metadata, action controls, a discussion area, and a long related-videos rail.

What it demonstrates ​

  • a watch-page layout with a large lead media area
  • a top application toolbar with search and utility actions
  • channel metadata and action groups
  • long-form supporting copy and community comments
  • a scrollable related-content column
  • repeated thumbnail cards using Image, Text, Button, Avatar, and Badge-like metadata patterns
