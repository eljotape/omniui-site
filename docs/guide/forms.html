Forms DSL ​

This guide documents the current form-control DSL:

  • Input
  • TextArea
  • Select
  • Slider
  • SpinButton
  • Checkbox
  • Toggle
  • Form defaults

Core rules ​

  • Label comes from []: [Email](Input.fill)
  • Required is inferred from trailing *: [Email*](Input.fill)
  • Field props are declared inline in component target:
    • flags: showLabel, showClearButton, showMask, disabled, readonly, checked, on, off, stepped
  • key/value: placeholder=, value=, state=, message=, prefix=, suffix=, leadingIcon=, trailingIcon=, rows=, min=, max=, step=
  • Field props can also be declared in child lines with - key / - key=value under any component line.
  • Validation is field-level (state, message), not a separate node.

Form defaults ​

~ Form works as a layout container with field defaults:

  • showLabels
  • gap=
  • requiredMark=
  • labelPosition=
  • size=
  • surface=
  • validationVisibility=

Example:

OmniUI
Codeomniui
~ Form showLabels gap=lg requiredMark=&quot;*&quot;
  [Email address*](Input.email.fill placeholder="name@example.com")
  [Search](Input.search.fill placeholder="Search teams" showClearButton)
  [First name](Input.fill value="Mark" state=success message="Looks good!")
  [Username*](Input.fill prefix="@" state=error message="Please choose a username.")

Multiline props:

OmniUI
Codeomniui
~ Form showLabels gap=lg
  [Email address*](Input.email.fill)
    - placeholder="name@example.com"
  [First name](Input.fill value="Mark")
    - state=success
    - message="Looks good!"
  [Username*](Input.fill)
    - prefix="@"
    - state=error
    - message="Please choose a username."

Input ​

OmniUI
Codeomniui
[Email address](Input.email.fill showLabel placeholder="name@example.com")
[Password*](Input.password.fill showLabel value="supersecret" showMask)
[Search](Input.search.fill showLabel placeholder="Search teams" showClearButton)
[Price](Input.fill showLabel suffix="USD")
[Amount](Input.fill showLabel trailingIcon=info)

Supported type/style tokens include: fill, outline, email, password, search, tel, url, number, sm, md, lg.

Slider ​

OmniUI
Codeomniui

[Quality](Slider.fill.stepped showLabel value="2" min="0" max="4" step="1")
[Risk threshold*](Slider.fill showLabel value="10" min="0" max="100" state=error message="Threshold is too low.")
