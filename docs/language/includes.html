Definitions ​

Definitions provides document-local reusable blocks with implicit slots.

Syntax ​

Define reusable entries:

OmniUI
Codeomniui
~ Definitions
  ~ RowItem
    ~ Stack horizontal gap=sm
      ~ avatar
      ~ title
    ~ Divider

Instantiate using include syntax:

OmniUI
Codeomniui
[>](RowItem)

Override slots from the include node:

OmniUI
Codeomniui
[>](RowItem)
  ~ avatar
    [A](Avatar.initials.sm)
  ~ title
    [Design review](Text.md)

Legacy form (still supported):

OmniUI
Codeomniui
~ RowItem
  ~ avatar
    [A](Avatar.initials.sm)
  ~ title
    [Design review](Text.md)

Behavior ​

  • Definitions can appear at most once per document.
  • Each direct child under Definitions creates one definition.
  • Definition names are unique in the document.
  • Definitions are local to the current file.
  • Expansion happens before rendering.
  • The renderer never sees Definitions entries.

Slot Rules ​

  • Slot placeholders are node names inside a definition that are not layout primitives, built-in components, or special keywords.
  • If an include/reference provides ~ slotName, that content replaces the slot.
  • If not provided, the slot keeps its default children.
  • Unknown slot overrides are reported as warnings.

Example ​

OmniUI
Codeomniui
~ Ui
  ~ Definitions
    ~ RowItem
      ~ Stack horizontal gap=sm
        ~ avatar
          [?](Avatar.placeholder.sm)
        ~ title
          [Untitled](Text.md)
      ~ Divider

  ~ Stack gap=sm
    [>](RowItem)
    [>](RowItem)
      ~ avatar
        [AB](Avatar.initials.sm)
      ~ title
        [Design review](Text.md)
