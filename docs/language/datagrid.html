DataGrid ​

Overview ​

  • DataGrid is the official OmniUI table surface for authored UIs.
  • DataGrid uses a Markdown table as its row/column source.
  • Internally, parser/runtime still use Table, TableRow, and TableCell nodes for Markdown table structure compatibility.

Use Cases ​

  • Use DataGrid for inbox-like rows, compact operational tables, and structured metadata views.
  • Use it when a plain Markdown table needs UI-oriented rendering semantics.
  • Prefer authoring DataGrid as the default table representation in new OmniUI files.

Modifiers ​

  • alternate alternates row backgrounds using a muted gray surface tone
  • fill expands the grid to the available width
  • border=value controls visible borders
  • scroll, scroll=vertical, scroll=horizontal, and scroll=both enable grid-owned scrolling
  • column sizing is inferred automatically when widths are not explicit

Border Values ​

  • Default when omitted: all
  • none
  • outer
  • innerRows
  • innerCols
  • all

Scroll ​

  • default when omitted: none
  • scroll means scroll=vertical
  • scroll=horizontal is useful when inferred minimum widths exceed the available container width
  • scroll=both enables both axes
  • scrollbar tracks are visible on enabled axes; thumbs reflect actual overflow
  • when a DataGrid lives inside Stack scroll, the renderer may reuse the parent scroll container instead of drawing nested scrollbars

      | Namecheap | Promotion |
      | Google | Updates |

      | Notifications | You have new activity | 17:10 |
