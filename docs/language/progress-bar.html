Progress Bar ​

Overview ​

  • ProgressBar represents determinate or indeterminate progress for a background task.
  • Use it for read-only status feedback where users should understand completion, but should not edit the value.
  • For editable ranges, use Slider instead.

Use Cases ​

  • File uploads, sync jobs, imports, and processing queues.
  • Inline progress inside Toast, cards, lists, or setup flows.
  • Long-running background tasks that need a clear percent-complete indicator.

Syntax ​

OmniUI
Codeomniui
[Label](ProgressBar.tokens attrs)

Common examples:

OmniUI
Codeomniui
[File upload](ProgressBar.fill.showLabel value="72")
[Syncing workspace](ProgressBar.fill.showLabel indeterminate)

Tokens ​

  • Size: xxs, xs, sm, md, lg, xxl (default md)
  • Layout: fill
  • State and feedback: showLabel, state=, message=, indeterminate, disabled
  • Rendering: skeleton

Attributes ​

  • showLabel
  • value="number"
  • min="number" (default 0)
  • max="number" (default 100)
  • state=default|hover|focused|active|success|warning|error
  • message="..."
  • indeterminate
  • disabled

Examples ​

OmniUI
Codeomniui
~ Ui
  ~ Stack gap=lg padding=20 width=720
    # Progress Bar - all combinations exercised
    Reference sample for determinate, indeterminate, semantic, and disabled progress states.

    ~ Grid cols=2 gap=lg
      ~ Stack gap=md
        [File upload](ProgressBar.sm.fill.showLabel value="28")
        [Workspace sync](ProgressBar.fill.showLabel value="72" state=success)
        [Security scan](ProgressBar.lg.fill.showLabel value="54" state=warning message="Scanning large archive.")

      ~ Stack gap=md
        [Syncing workspace](ProgressBar.fill.showLabel indeterminate)
        [Publishing release](ProgressBar.fill.showLabel value="16" state=error message="Connection dropped.")
        [Queued export](ProgressBar.fill.showLabel value="40" disabled)
