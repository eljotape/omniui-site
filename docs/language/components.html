UI Components ​

OmniUI documents UI components as individual reference pages. This index page exists to explain the component model and to provide a single grid of everything currently defined for this version.

How Components Work ​

  • Components are semantic UI elements expressed through Markdown link syntax.
  • Component content supports inline Markdown inside [], including bold, italic, strikethrough, highlight, inline code, links, images, emoji, escaped shortcut text, and <br> line breaks.
  • Each component page documents the default rendering, common use cases, supported tokens, and exhaustive examples.
  • Implemented components have dedicated renderer behavior.
  • Pending components already have reserved language pages so the docs structure stays stable as the renderer grows.
