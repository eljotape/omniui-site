Text ​

Text is not part of the original UI component list, but it is implemented today and has a dedicated renderer, so it belongs in the reference.

Overview ​

  • A lightweight textual primitive used for standalone labels, helper copy, and compact inline content that should not be drawn as a control.

Use Cases ​

  • Use Text for secondary labels, metrics, inline descriptors, and simple copy blocks inside Layout Primitives.
  • Use size tokens to establish hierarchy without switching to another component.

Sizes ​

  • Supported today: xxs | xs | sm | md | lg | xxl

Content ​

  • Supports plain text
  • Supports inline Markdown emphasis inside component content: **bold**, *italic*, _italic_, ***bold italic***, ~~strike~~, ==highlight==, and `code`
  • Supports standard inline Markdown links like [Open docs](https://example.com)
  • Supports inline images like ![Logo](logo.png) inside component content
  • Supports inline image options such as ![Logo](logo.png | border=none) and sizing options like ![Logo](logo.png | width=sm height=sm)
  • Supports explicit inline line breaks with <br>
  • Supports fenced code blocks using triple backticks
  • Supports inline icons
  • Supports inline badge tokens for enclosed alphanumeric forms (for example, enclosed A, 1, and 10)
  • Wraps by default
  • nowrap keeps the text on a single line
  • wrap is available for explicit readability when reviewing tokens in the editor
  • Inline code uses a system monospace font stack
  • Fenced code blocks use a system monospace font stack on a subtle code surface

See also: /language/text-expands

Anchoring ​

  • Supports @id
