Icon Mapping ​

OUi converts supported inline pictographic tokens into SVG icons through the semantic mapping layer.

It also supports an explicit semantic icon component:

OmniUI
Codeomniui
[search](Icon)
[mail](Icon.sm)
[settings](Icon.lg)

Use the explicit Icon component when you want to render the semantic icon itself, for example inside tables, icon catalogs, and documentation grids.

Pipeline ​

token -> normalize -> semantic -> icon asset

Key files:

  • apps/editor/src/icons/normalize-emoji.ts
  • apps/editor/src/icons/emoji-catalog.ts
  • apps/editor/src/icons/icon-loader.ts
  • apps/editor/src/icons/icon-registry.ts

Goal ​

  • Keep the token-to-icon behavior explicit and auditable.
  • Avoid shipping a full icon library bundle when only individual assets are needed.
  • Reuse semantic icon names across components, text, and navigation patterns.

Badge Tokens ​

Some enclosed alphanumeric token aliases are intentionally rendered as inline badges instead of icons.

  • A/B/AB/CL/O enclosed forms
  • 0-9 enclosed forms
  • 10 enclosed form

They bypass the icon pipeline and render their letter/number content inside a badge shape.
