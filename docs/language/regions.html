Layout Primitives ​

Overview ​

  • This page documents the available layout primitives in OUi.
  • Use these directives to define root structure, one-dimensional flow, two-dimensional grids, spacing gaps, and floating layers.

Syntax ​

  • Root: ~ Ui
  • One-dimensional flow: ~ Stack ...
  • Two-dimensional flow: ~ Grid ...
  • Flexible gap helper: ~ Spacer
  • Floating layer: ~ Overlay type=... anchor=@...
  • Mobile bottom navigation shell is documented under Bottom App Bar.

Examples ​

  • See the executable OmniUI samples under Ui, Stack, Grid, Card, Scroll Examples, Spacer, and Overlay below.

Ui ​

Description:

  • The mandatory top-level visual container for a OUi document.

Rules:

  • Every .ui document must start with exactly one root ~ Ui node.
  • Ui is the document root directive, not a layout primitive.
OmniUI
Codeomniui
~ Ui
  ~ Stack
    # Ui root
    Plain content inside screen

Stack ​

Description:

  • A one-dimensional layout primitive that arranges children in a vertical or horizontal flow.

Use cases:

  • Use vertical Stack for page sections, forms, and grouped content.
  • Use horizontal Stack for toolbars, action rows, and inline groups.
  • Use Spacer inside a horizontal stack to push items apart.
  • Use scroll when the stack should keep a fixed viewport and expose overflow through a scrollbar.

Props exercised today:

  • vertical by default
  • horizontal
  • scroll
  • scrollbar=content | container
  • alignH=start | center | end | between | stretch
  • alignV=start | center | end | between | stretch
  • rounded
  • rounded=sm | md | lg | xl
  • surface=muted | raised | inverse
  • role=...
  • w= / width= and h= / height= (aliases)
  • fill shorthand (w=100% h=100%)

Scroll behavior:

  • Stack scroll renders a scrollbar track for the selected axis.
  • The thumb scales according to the ratio between viewport size and total content size.
  • The track is rendered as an outlined empty channel instead of a filled surface.
  • The thumb stays edge-aligned, superposed on that channel, and uses themed surface fill.
  • The scrollbar gutter is reserved up front, so fill children reflow against the remaining space.
  • Vertical stacks draw vertical scrollbars. Horizontal stacks draw horizontal scrollbars.
  • scrollbar=container aligns the track to the container edge instead of the padded content edge.
  • Use h=fill / height=fill when a stack should expand only in the vertical axis without also stretching in width.
  • Use w=100% / h=100% for explicit percentage sizing when needed.
OmniUI
Codeomniui
~ Ui
  ~ Stack role=page
    # Stack vertical
    [Primary](Button.primary.md)
    [Secondary](Button.secondary.md)

    ~ Stack horizontal role=toolbar
      [[list](Icon)](Button.ghost.sm)
      [[search](Icon) Search](Input.search.fill)
      ~ Spacer
      [[settings](Icon)](Button.ghost.sm)

    ~ Stack horizontal alignH=end gap=sm
      [Cancel](Button.secondary.md)
      [Delete](Button.danger.md)

    ~ Stack alignH=center border width=280
      [Centered block title](Text.md)
      [This text stays centered inside the stack cross-axis.](Text.sm.wrap)

    ~ Stack border rounded=lg
      [Rounded layouts are opt-in.](Text.sm)
      [Default layout corners stay square.](Text.sm)

    ~ Stack scroll role=list scrollbar=container
      [[inbox](Icon) Inbox](NavItem.active)
      [⭐ Starred](NavItem.md)
      [[clock](Icon) Snoozed](NavItem.md)
      [[outbox](Icon) Sent](NavItem.md)
      [[file-edit](Icon) Drafts](NavItem.md)
      [[tag](Icon) Tags](NavItem.md)
      [[trash](Icon) Trash](NavItem.md)

    [The toolbar uses Spacer to separate the leading search field from the trailing action.](Text.sm)

    ~ Stack surface=muted border
      [Muted surface groups related controls with a light gray fill.](Text.sm)

    ~ Stack surface=raised border
      [Raised surface uses a softer elevated tone for grouped content.](Text.sm)

Grid ​

Description:

  • A two-dimensional layout primitive that distributes children across configured column and row tracks.

Use cases:

  • Use Grid for compact dashboards, metric blocks, control galleries, and evenly distributed content groups.
  • Use it when one-dimensional stacking is not enough to communicate grouping.

Props exercised today:

  • cols=2
  • cols=3
  • cols=18,1fr,18
  • rows=auto,1fr,auto
  • rounded
  • rounded=sm | md | lg | xl
  • surface=muted | raised | inverse
  • alignH=start | center | end | stretch (cell default)
  • alignV=start | center | end | stretch (cell default)
  • simple child distribution

Track templates:

  • cols= accepts numeric count (cols=3) or template list (cols=72,320,1fr).
  • rows= accepts numeric count (rows=3) or template list (rows=64,1fr,64).
  • Supported template units: pixel number (72), percentage (30%), fraction (1fr), and auto.
OmniUI
Codeomniui
~ Ui
  ~ Stack
    # Grid

    ~ Grid cols=2
      [Primary](Button.primary.md)
      [Secondary](Button.secondary.md)
      [⭐ Starred](NavItem.md)
      [12](Badge.md)

    ~ Grid cols=3
      [Metric A](Text.sm)
      [Metric B](Text.sm)
      [Metric C](Text.sm)
      [42](Badge.md)
      [13](Badge.md)
      [7](Badge.md)

    ~ Grid cols=2 surface=muted border
      [Muted cell](Text.sm)
      [Muted cell](Text.sm)

    ~ Grid cols=2 surface=raised border rounded=md
      [Rounded grid](Text.sm)
      [Opt-in radius](Text.sm)

    ~ Grid cols=2 border alignH=center alignV=center
      [Centered](Badge.md)
      [Cell defaults](Text.sm)

    ~ Grid cols=72,1fr,72 rows=auto,1fr,auto border width=520 height=220 padding=0
      [Top](Text.sm)
      [Top](Text.sm)
      [Top](Text.sm)
      [Left](Text.sm)
      [Main](Text.sm)
      [Right](Text.sm)
      [Bottom](Text.sm)
      [Bottom](Text.sm)
      [Bottom](Text.sm)

Card ​

Description:

  • A container layout primitive for grouped card content.
  • Behaves like a bordered stack container and supports nested children.

Use cases:

  • Use ~ Card when content needs title/body/actions structure.
  • Use it to group related controls without flattening everything into a single inline label.

Props exercised today:

  • vertical by default
  • horizontal
  • gap=...
  • padding= (supports multiple space-separated values or granular attributes)
  • w= / h= / width= / height=
  • fill
  • border
  • surface=muted | raised | inverse
  • rounded
  • role=...
OmniUI
Codeomniui
~ Ui
  ~ Stack gap=md
    # Card

    ~ Card gap=sm padding=12
      [Billing summary](Text.md)
      [Monthly usage is within the configured budget.](Text.sm)
      ~ Stack horizontal alignH=end gap=sm
        [Dismiss](Button.secondary.sm)
        [Open report](Button.primary.sm)

    ~ Card horizontal gap=md padding=12
      ![Usage chart placeholder]()
      ~ Stack gap=xs
        [Usage trends](Text.md)
        [Last 30 days](Text.sm)

Spacer ​

Description:

  • A non-visual layout primitive that consumes free space inside a stack, most commonly in horizontal layouts.

Use cases:

  • Use Spacer to push trailing actions to the far side of a toolbar or row.
  • Use it to separate left-aligned and right-aligned content without hardcoded spacing.
  • Use width= / height= when a spacer should reserve explicit space.
OmniUI
Codeomniui
~ Ui
  ~ Stack
    # Spacer

    ~ Stack horizontal
      [Left](Text.md)
      ~ Spacer
      [Right](Text.md)

    ~ Stack horizontal
      [Start](Text.md)
      ~ Spacer width=lg
      [End](Text.md)

    ~ Stack border
      [Top](Text.md)
      ~ Spacer height=xl
      [Bottom](Text.md)

Overlay ​

Description:

  • A floating layer attached to the main layout, usually positioned relative to an anchored component.

Use cases:

  • Use Overlay for tooltips, contextual popovers, dialog-like surfaces, bottom sheets, FAB actions, and temporary floating UI.
  • Use anchors when the floating layer should clearly point to a visible trigger.

Current notes:

  • Overlay is declared with ~ Overlay.
  • It supports type=..., anchor=@..., and placement=....
  • Tooltips also support inverted to swap the default tooltip fill and text colors.
  • Drawers and bottom sheets support backdrop to render the default dimmed backdrop behind the panel.
  • It also supports surface=muted | raised for floating container tone.
  • Overlay variants are documented on the Overlay Types page.
OmniUI
Codeomniui
~ Ui
  ~ Stack horizontal
    ~ Stack border
