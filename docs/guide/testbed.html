Testbed ​

/examples/testbed/testbed.ui remains the reference document for exercising the parser and the playground renderer.

Usage ​

  • it can be opened from the editor Snippet dropdown
  • it is useful for quick regression checks
  • it concentrates buttons, inputs, navigation, tables, and overlay structures in one place
  • markdown checkbox shortcuts, parenthesized radios, badge shortcuts, and literal escape are exercised directly in the visible layout
  • HTML comments are ignored by the parser and can be used as authoring notes
  • enclosed alphanumeric emojis are exercised as inline badge tokens
  • stack alignment is exercised with a destructive action row aligned to end
  • table cell alignment shortcuts are exercised with centered and right-aligned cell content markers
  • layout rounding is exercised with square-by-default containers and an explicit rounded=lg example
  • spacer explicit sizing is exercised with width= and height=
