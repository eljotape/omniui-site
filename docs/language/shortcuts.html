Shortcut Layer ​

OmniUI supports a small shortcut layer on top of the core DSL.

These shortcuts are authoring conveniences. They expand into the normal semantic component model during parsing.

Implemented today ​

Standalone badge ​

OmniUI
Codeomniui
(12)

Parses as:

OmniUI
Codeomniui
[12](Badge)

Checkbox shortcut ​

OmniUI
Codeomniui
[ ] Draft
[x] Approved

Parses as Checkbox components.

Divider shortcut ​

OmniUI
Codeomniui
---

Parses as:

OmniUI
Codeomniui
~ Divider

~ Divider uses fill by default.

Parenthesized choice controls ​

OmniUI
Codeomniui
( ) Option A
(o) Option B

( ) Optional
(x) Required

Rules:

  • a contiguous block with any (x) becomes Checkbox
  • otherwise the block becomes Radio

Table cell alignment shortcuts ​

OmniUI
Codeomniui
| Name | Team | State |
| --- | --- | --- |
| Nora | : Design systems : | Ready : |

Rules:

  • : value : centers that cell
  • value : right-aligns that cell
  • the shortcut overrides the column default only for that cell

Literal escape ​

Prefix any heuristic shortcut with !! to render it literally.

Examples:

OmniUI
Codeomniui
!!(12)
!![x] Done
!!---

Rendered result:

  • (12)
  • [x] Done
  • ---

The !! prefix is removed during parsing and the remaining content is treated as plain text.

Not implemented yet ​

The following ideas are still documented as future shortcut syntax, not active parser behavior:

  • slot rows with |
  • * as a dedicated icon placeholder token

% DataGroup ... is implemented as a parser expansion directive and is documented at /language/datagroup. By default it preserves repeated content; fake or fake=[...] enables text replacement.
